# TaskBoard — Semana 7

Proyecto desarrollado para la asignatura **Integración de Sistemas** de la Universidad Pedagógica de El Salvador.

## Descripción

Durante la Semana 7 se implementaron vistas dinámicas con **Blade** para mostrar la información de comercios y transacciones del proyecto TaskBoard.

## Funcionalidades realizadas

- Listado de comercios afiliados.
- Vista de detalle de cada comercio.
- Visualización de transacciones asociadas.
- Uso de `@if`, `@forelse` y otras directivas Blade.
- Layout reutilizable con `@extends`, `@section` y `@yield`.
- Componente `<x-badge-estado>` para mostrar el estado de las transacciones.
- Componente `<x-badge-actividad>` para indicar si un comercio tiene actividad.
- Uso de Route Model Binding.
- Conteo de transacciones con `withCount()`.

## Tecnologías

- Laravel
- PHP
- Blade
- MySQL / MariaDB
- Composer
- Git y GitHub
